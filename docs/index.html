Raspberry Pi Backup – Main Features

With pibackup, you can create a reliable Raspberry Pi backup directly on your SD card, SSD, or HDD. This tool supports live backup of running systems without shutdown, including the first two partitions (/boot and /root).

  • Simple graphical user interface – no installation required
  • 64-bit Linux application – runs directly
  • Automatically backs up the first two partitions (/boot and /root)
  • Live backup support – backup running Raspberry Pi systems without shutdown
  • Exclude file support for removing unwanted data and folders
  • Optional removal of SSH and DHCP configs from the backup
  • Image shrinking using resize2fs and compression with zstd
  • Backups saved as .img.zst (optional)
  • Empty sectors filled with 0xFF for better compression and security
  • Compatible with SD cards, SSDs, HDDs, and other block devices

Raspberry Pi Backup – Restore Options

You can use pibackup to selectively restore your Raspberry Pi backup without affecting other partitions. Adjust partition sizes and preview the layout using the live GUI.

  • Restore from .img or .img.zst directly – no manual steps
  • Selective restore: only system partitions (/boot and /root) – other partitions stay intact
  • Target device selection via dropdown menu
  • Adjust partition size via scrollbar or slider
  • Live preview of planned partition layout (grid view)
  • Optional selective partition deletion
  • File system auto-resized to fit the new partition size

Raspberry Pi Backup – FAQ

How do I back up my Raspberry Pi?

With pibackup, you can create a complete Raspberry Pi backup while the system is running, without shutting it down.

Can I restore only the system partitions?

Yes, pibackup allows selective restore of /boot and /root without affecting other partitions on your SD card or SSD.

Does pibackup support SSDs and HDDs?

Yes, pibackup works seamlessly with SD cards, SSDs, HDDs, and other block devices.
