pibackup

Raspberry Pi Backup & Restore Tool

🔒 Backup Instructions

  1. Insert an SD/SSD or select a running system.
  2. Select the device to be backed up.
  3. Choose the storage location for the backup image (.img).
  4. Enable optional Exclude (removes files/folders) and Compress (creates .img.zst).
  5. Partitions are automatically shrunk (root partition only).
  6. Start the backup and monitor progress.

♻️ Restore Instructions

  1. Select Restore to device after starting pibackup.
  2. Select the desired backup image.
  3. Select the target device (⚠️ will be overwritten).
  4. Default size is maximum available, but you can adjust via slider.
  5. If more space is needed, partitions 3 and 4 can be deleted (checkbox option).
  6. The target partitions are shown in a grid as they will look after restore.
  7. Start restore and monitor progress.

💡 Tips

A standard image always includes the MBR.
Regularly create backups to avoid data loss.
Restoring to smaller or larger media is supported.
Keep a ready-to-use emergency image.

🔒 Backup-Anleitung

  1. Eine SD-/SSD-Karte einlegen oder ein laufendes System auswählen.
  2. Das zu sichernde Gerät auswählen.
  3. Den Speicherort für das Backup-Image festlegen (.img).
  4. Optional Exclude aktivieren (entfernt Dateien/Ordner) und Compress (erstellt .img.zst).
  5. Die Root-Partition im Image wird automatisch verkleinert.
  6. Backup starten und den Fortschritt beobachten.

♻️ Restore-Anleitung

  1. Nach dem Start von pibackup Restore to device auswählen.
  2. Das gewünschte Backup-Image auswählen.
  3. Das Zielgerät auswählen (⚠️ wird überschrieben).
  4. Standardmäßig wird die maximale Größe genutzt, Anpassung per Schieberegler möglich.
  5. Falls mehr Platz benötigt wird, können Partition 3 und 4 per Checkbox gelöscht werden.
  6. Die Zielpartitionen werden in einem Raster so angezeigt, wie sie nach dem Restore aussehen werden.
  7. Restore starten und den Fortschritt beobachten.

💡 Tipps

Ein Standard-Image enthält immer auch den MBR.
Erstellen Sie regelmäßig Backups, um Datenverlust zu vermeiden.
Das Wiederherstellen auf kleinere oder größere Medien ist möglich.
Bewahren Sie ein Notfall-Image griffbereit auf.
