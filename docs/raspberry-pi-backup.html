pibackup – Raspberry Pi Backup & Restore Tool

Mit pibackup kannst du ein komprimiertes Image (.img.zst) deines Raspberry Pi erstellen. Dieses Backup kann später auf dieselbe SD-Karte, eine größere oder kleinere Karte oder sogar auf SSD/HDD wiederhergestellt werden. Spare Speicherplatz durch Schrumpfen der Images und behalte die volle Kontrolle über deine Daten.

Hauptfunktionen

Backup

Sichere die ersten zwei Partitionen deines Raspberry Pi zuverlässig.

Shrink & Compress

Reduziere die Image-Größe und komprimiere sie im Zstandard-Format (.zst).

Restore

Stelle das Backup auf der gleichen oder einer anderen SD-Karte wieder her.

Exclude-File

Schließe unnötige Dateien aus, um Speicherplatz zu sparen.

Anleitung & Tipps

Erstelle regelmäßig Backups, um Datenverlust zu vermeiden. Du kannst bestehende Backups auf kleinere Medien schreiben oder ein Notfall-Image bereithalten, um dein System im Ernstfall schnell wiederherzustellen.
