Raspberry Pi Backup & Restore Guide with pibackup

Why a Backup Is Important

The Raspberry Pi is often used as a server, media center, or control system. If the SD card or SSD fails, all data may be lost. pibackup allows you to create complete backups and restore them safely to any SD card, USB stick, SSD, or internal partition.

Requirements

  • A Raspberry Pi with a running system
  • A second SD card, USB stick, or external SSD/HDD with enough space
  • Or an internal SSD with a free 3rd or 4th partition with enough space
  • Installed pibackup tool (GitHub Project Page)

Step 1: Start pibackup

Run pibackup via your desktop launcher or double-click the start script. The GUI opens automatically, no terminal commands required.

Step 2: Create a Backup

Select your source device (e.g. /dev/mmcblk0) in the GUI. pibackup will:

  • Create an image of the first two partitions (boot + root)
  • Optionally optimize the image by removing unnecessary files
  • Compress to .img.zst (optional)

Step 3: Restore a Backup

Open pibackup and select Restore in the GUI.

  1. Choose the backup file (e.g., mybackup.img.zst)
  2. Select the target device (SD card, USB, SSD/HDD)
  3. Select options before confirming restore:
    • Restore partition size – default = maximum available space, or specify custom size
    • New device UUID – assign a new UUID if needed
    • Partitions to delete – optionally delete partition 3 or partition 3 and 4 to free space
  4. Confirm the restore process

pibackup writes the image, applies selected options, and adjusts partitions as needed.

Step 4: Test the Backup

  • Boot the Raspberry Pi with the restored media
  • pibackup performs internal validation (e.g., e2fsck)
  • Verify system functionality (SSH, services, desktop)

FAQ

Can I restore to a smaller SD card or SSD?

Yes. The restore partition is resized automatically, or you can specify a custom size. Optionally delete partition 3 or 3+4 to free space.

Does pibackup support custom restore partition sizes?

Yes. Default = max available space; you can also set a custom size via GUI slider.

How does pibackup test the restored backup?

Internal checks like e2fsck are run automatically during restore.

Advantages

  • GUI-only operation, no terminal commands
  • Safe and flexible backup/restore
  • Supports SD, USB, SSD/HDD, internal partitions
  • Custom restore options: partition size, delete partition 3/4, new UUID
  • Efficient compression with Zstandard
