pibackup – Raspberry Pi Backup & Restore Tool

Mit pibackup kannst du ein komprimiertes Image (.img.zst) deines Raspberry Pi erstellen. Dieses Backup kann später auf dieselbe SD-Karte, eine größere oder kleinere Karte oder sogar auf ein anderes Laufwerk oder vorhandenes Image wiederhergestellt werden. Spare Speicherplatz durch Schrumpfen der Images und behalte die volle Kontrolle über deine Daten.

Hauptfunktionen

Backup

Sichere ein laufendes System, ein externes Laufwerk oder ein vorhandenes Image zuverlässig.

Shrink & Compress

Reduziere die Image-Größe und komprimiere sie im Zstandard-Format (.zst).

Restore

Stelle Backups auf demselben oder einem anderen Medium wieder her.

Exclude-File

Schließe unnötige Dateien aus, um Speicherplatz zu sparen.

Anleitung & Tipps

1. Backup erstellen

  1. pibackup starten, falls es noch nicht läuft.
  2. Das zu sichernde Device auswählen: laufendes System, ein externes Laufwerk oder ein vorhandenes Image.
  3. Optional: Eine Datei mit zu entfernenden Dateien auswählen (Exclude-File), um unnötige Daten auszuschließen.
  4. Speicherort für das Backup-Image festlegen (.img.zst).
  5. Backup starten und den Fortschritt beobachten.

2. Backup schrumpfen & komprimieren

  1. Optional: Unnötige Dateien über die Exclude-Funktion ausschließen.
  2. pibackup schrumpft die Partitionen auf die minimale Größe.
  3. Das Image wird automatisch im Zstandard-Format komprimiert.

3. Backup wiederherstellen

  1. Ziel-Device auswählen (kann gleiches oder anderes Medium sein).
  2. pibackup starten und das gewünschte Backup-Image laden.
  3. Wiederherstellung starten – Fortschrittsanzeige beobachten.
  4. Nach Abschluss das Device sicher entfernen und ggf. Raspberry Pi starten.

Tipps für maximale Sicherheit

  • Regelmäßig Backups erstellen, z. B. wöchentlich.
  • Backup-Images auf einem zweiten Medium speichern.
  • Ein Notfall-Image griffbereit halten, um das System schnell wiederherzustellen.
