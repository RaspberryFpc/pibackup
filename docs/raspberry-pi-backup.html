pibackup – Raspberry Pi Backup & Restore Tool

With pibackup you can create a compressed image (.img or .img.zst) of your Raspberry Pi. This backup can later be restored to the same SD card, a larger or smaller one, or another drive. Save storage space by shrinking the images while keeping full control over your data.

Main Features

Backup

Securely back up a running system or an external drive by creating a standard image that includes the MBR.

Shrink & Compress

Automatically resize partitions and optionally compress the image in Zstandard format (.zst).

Restore

Restore backups to the same or a different device safely.

Exclude File

Exclude unnecessary files to save storage space.

Instructions & Tips

1. Creating a Backup

  1. Start pibackup if it is not already running.
  2. Select the device to back up: running system or external drive.
  3. Optional: Select a file with excluded files (Exclude-File) to omit unnecessary data.
  4. Choose the storage location for the backup image. By default, a .img file is created; if the Compress option is enabled, a .img.zst file will be generated automatically.
  5. Start the backup and monitor the progress.

2. Shrinking & Compressing

  1. If an Exclude-File is selected, pibackup first removes all specified files and folders from the backup image.
  2. After that, all partitions are automatically resized (shrunk) to their minimum size.
  3. If the Compress option is enabled, the image is then compressed in Zstandard format (.zst).

3. Restoring a Backup

  1. Start pibackup and select "Restore to device".
  2. Select the backup image you want to restore.
  3. Select the target device (must not be the running system; using a different medium is recommended).
  4. The target partitions are displayed in a grid showing their layout after the restore.
  5. By default, each restored partition is set to the maximum available size. You can adjust the size using the slider.
  6. If the target device is too small, you can free up additional space by enabling the checkboxes to delete partitions 3 and 4.
  7. Start the restoration and monitor the progress.
  8. After completion, safely remove the device and start the Raspberry Pi if needed.

Tips for Maximum Safety

  • Create backups regularly, e.g., weekly.
  • Store backup images on a secondary medium.
  • Keep a ready-to-use emergency image for quick system recovery.
