pibackup – Raspberry Pi Backup & Restore Tool

With pibackup you can create a compressed image (.img.zst) of your Raspberry Pi. This backup can later be restored to the same SD card, a larger or smaller one, another drive, or even an existing image. Save storage space by shrinking the images while keeping full control over your data.

Main Features

Backup

Securely back up a running system, an external drive, or an existing image.

Shrink & Compress

Reduce image size and compress it in Zstandard format (.zst).

Restore

Restore backups to the same or a different device safely.

Exclude File

Exclude unnecessary files to save storage space.

Instructions & Tips

1. Creating a Backup

  1. Start pibackup if it is not already running.
  2. Select the device to back up: running system, external drive, or existing image.
  3. Optional: Select a file with excluded files (Exclude-File) to omit unnecessary data.
  4. Choose the storage location for the backup image (.img.zst).
  5. Start the backup and monitor the progress.

2. Shrinking & Compressing

  1. Optionally exclude unnecessary files using the Exclude function.
  2. pibackup will shrink the partitions to the minimum size.
  3. The image is automatically compressed in Zstandard format (.zst).

3. Restoring a Backup

  1. Select the backup image you want to restore.
  2. Select the target device (must not be the running system; using a different medium is recommended).
  3. The target partitions are displayed in a grid showing their layout after the restore.
  4. By default, each restored partition is set to the maximum available size. You can adjust the size using the slider.
  5. If the target device is too small, you can free up additional space by enabling the checkboxes to delete partitions 3 and 4.
  6. Start the restoration and monitor the progress.
  7. After completion, safely remove the device and start the Raspberry Pi if needed.

Tips for Maximum Safety

  • Create backups regularly, e.g., weekly.
  • Store backup images on a secondary medium.
  • Keep a ready-to-use emergency image for quick system recovery.
