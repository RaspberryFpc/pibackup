pibackup

Raspberry Pi Backup & Restore Tool

Funktionen

  • Sichere Backups vom laufenden System oder von externen Laufwerken.
  • Erstellt ein vollständiges Image inklusive MBR.
  • Optionale Exclude-Datei, um unnötige Daten zu entfernen.
  • Automatisches Shrinking der Root-Partition.
  • Kompression im Zstandard-Format (.zst).
  • Sichere Wiederherstellung mit Partitionsvorschau und Optionen für Speicherplatz.

Backup-Anleitung

  1. pibackup starten.
  2. Das zu sichernde Device (SD/SSD/USB) auswählen.
  3. Optional: Datei mit auszuschließenden Dateien/Ordnern (.exclude) auswählen.
  4. Speicherort für das Backup-Image festlegen (.img).
  5. Wenn „Compress“ aktiviert ist, wird automatisch eine .img.zst-Datei erstellt.
  6. Backup starten und den Fortschritt beobachten.

Restore-Anleitung

  1. pibackup starten und Restore to Device auswählen.
  2. Das gewünschte Backup-Image auswählen (.img oder .img.zst).
  3. Zielgerät auswählen (nicht das laufende System!).
  4. Die geplanten Zielpartitionen werden in einem Grid angezeigt.
  5. Standardgröße ist „Maximum available“. Mit einem Slider kann die Größe angepasst werden.
  6. Falls die Partition zu klein ist, können optional die 3. und 4. Partition per Checkbox entfernt werden.
  7. Restore starten und den Fortschritt überwachen.

Anleitung & Tipps

Erstelle regelmäßig Backups, um Datenverlust zu vermeiden. Halte ein Notfall-Image bereit, um dein System im Ernstfall schnell wiederherzustellen.

Features

  • Secure backups from the running system or external drives.
  • Creates a complete image including the MBR.
  • Optional Exclude file to remove unnecessary data.
  • Automatic shrinking of the root partition.
  • Compression in Zstandard format (.zst).
  • Safe restore with partition preview and space-saving options.

Backup Guide

  1. Start pibackup.
  2. Select the device to back up (SD/SSD/USB).
  3. Optional: Select a file with excluded files/folders (.exclude).
  4. Choose the storage location for the backup image (.img).
  5. If “Compress” is enabled, a .img.zst file is created automatically.
  6. Start the backup and monitor the progress.

Restore Guide

  1. Start pibackup and select Restore to Device.
  2. Select the desired backup image (.img or .img.zst).
  3. Choose the target device (not the running system!).
  4. The planned target partitions are displayed in a grid.
  5. Default size is “Maximum available”. A slider allows manual resizing.
  6. If the partition is too small, you can optionally remove the 3rd and 4th partitions via checkboxes.
  7. Start the restoration and monitor the progress.

Instructions & Tips

Create regular backups to avoid data loss. Keep a ready-to-use emergency image to quickly restore your system if needed.
