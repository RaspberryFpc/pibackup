Raspberry Pi Backup – Hauptfunktionen

Mit pibackup können Sie ein zuverlässiges Raspberry Pi Backup auf SD-Karte, SSD oder HDD erstellen. Unterstützt Live-Backups laufender Systeme inklusive der ersten beiden Partitionen (/boot und /root).

Eine ausführliche Schritt-für-Schritt-Anleitung finden Sie im Raspberry Pi Backup- & Restore-Handbuch.

  • Einfache grafische Benutzeroberfläche
  • 64-Bit Linux-Anwendung
  • Automatisches Backup der ersten beiden Partitionen (/boot und /root) inklusive MBR
  • Live-Backup-Unterstützung – Sicherung laufender Systeme
  • Unterstützung für Exclude-Dateien zum Entfernen unerwünschter Daten
  • Optionale Entfernung von SSH- und DHCP-Konfigurationen
  • Image-Verkleinerung mit resize2fs und Komprimierung mit zstd
  • Backups werden optional als .img.zst gespeichert
  • Leere Sektoren werden mit 0xFF gefüllt für bessere Komprimierung und Sicherheit
  • Kompatibel mit SD-Karten, SSDs, HDDs, USB-Laufwerken und NAS

Raspberry Pi Backup – Wiederherstellung

Mit pibackup können Sie /boot und /root vollständig wiederherstellen, inklusive MBR (Sektor 0). Das Backup umfasst immer den Bereich von Sektor 0 bis zum Ende der zweiten Partition. Die endgültige Größe der /root-Partition kann vor dem Schreiben über die Live-GUI angepasst werden.

  • Wiederherstellung direkt aus .img oder .img.zst
  • SSH beim ersten Start aktivieren
  • Benutzername und/oder Passwort setzen oder ändern
  • WLAN konfigurieren – SSID und Passwort (PSK) setzen oder ändern
  • Live-Vorschau der Partitionsaufteilung
  • Optionales Löschen vorhandener Partitionen auf dem Zielgerät
  • Anpassung der /root-Partitionsgröße per Schieberegler
  • Dateisystem wird automatisch passend vergrößert oder verkleinert

FAQ

Wie kann ich meine Raspberry Pi SD-Karte sichern?

Mit pibackup können Sie ein vollständiges Backup Ihrer Raspberry Pi SD-Karte erstellen. Das Tool unterstützt Live-Backups laufender Systeme, sodass kein Herunterfahren erforderlich ist.

Wie erstelle ich ein Raspberry Pi Image-Backup?

Mit pibackup können Sie eine komprimierte .img.zst-Datei Ihres Raspberry Pi erstellen. Dieses Backup kann später auf dieselbe SD-Karte, eine größere oder kleinere Karte oder auch auf SSD/HDD wiederhergestellt werden.

Kann ich mein Raspberry Pi Backup auf USB oder NAS speichern?

Ja, Backups können auf externen USB-Laufwerken, SSDs, HDDs oder direkt auf NAS gespeichert werden.

Ist pibackup eine Alternative zu raspiBackup?

Ja. pibackup ist eine portable Alternative zu raspiBackup mit grafischer Oberfläche, Live-Backup-Funktion und moderner zstd-Komprimierung.

Was wird immer gesichert?

pibackup sichert immer /boot und /root inklusive MBR. Das Backup deckt alles von Sektor 0 bis zum Ende der zweiten Partition ab.

Wie funktioniert die Wiederherstellung?

Bei der Wiederherstellung werden /boot und /root vollständig inklusive MBR zurückgeschrieben. Zusätzlich können SSH aktiviert, Benutzername und Passwort geändert und WLAN konfiguriert werden.
