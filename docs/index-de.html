Raspberry Pi Backup – Hauptfunktionen

Mit pibackup erstellen Sie ein zuverlässiges Raspberry Pi Backup einer SD-Karte, SSD oder HDD. Unterstützt werden Live-Backups laufender Systeme inklusive der ersten beiden Partitionen (/boot und /root).

Eine vollständige Schritt-für-Schritt-Anleitung finden Sie in der Raspberry Pi Backup- & Restore-Anleitung.

  • Einfache grafische Oberfläche – keine Installation erforderlich
  • 64-Bit-Linux-Anwendung – läuft direkt
  • Automatisches Backup der ersten zwei Partitionen (/boot und /root) einschließlich MBR
  • Unterstützung für Live-Backups – Backup ohne Neustart
  • Exclude-Datei zum Ausschließen unerwünschter Daten
  • Optionales Entfernen von SSH- und DHCP-Konfigurationen
  • Image-Verkleinerung mit resize2fs und Kompression mit zstd
  • Backups optional als .img.zst
  • Leere Sektoren werden mit 0xFF gefüllt – bessere Kompression & Sicherheit
  • Kompatibel mit SD-Karten, SSDs, HDDs, USB-Laufwerken und NAS

Raspberry Pi Backup – Wiederherstellungsoptionen

Mit pibackup stellen Sie /boot und /root vollständig wieder her – inklusive MBR (Sektor 0). Das Backup umfasst immer den Bereich von Sektor 0 bis zum Ende der zweiten Partition. Die endgültige Größe der /root-Partition kann vor dem Schreiben in der Live-GUI angepasst werden.

  • Direktes Wiederherstellen aus .img oder .img.zst
  • Anpassen der /root-Partitionsgröße per Schieberegler
  • Dateisystem wird automatisch auf die neue Größe erweitert
  • SSH beim ersten Start aktivieren
  • Benutzername und/oder Passwort setzen oder ändern
  • WLAN konfigurieren – SSID und Passwort (PSK) festlegen
  • Live-Vorschau des Partitionslayouts
  • Optionales Löschen vorhandener Partitionen auf dem Zielgerät
  • Dateisystem wird automatisch passend erweitert

FAQ

Wie sichere ich meine Raspberry-Pi-SD-Karte?

Mit pibackup können Sie ein vollständiges Raspberry Pi SD-Karten-Backup erstellen. Das Tool unterstützt Live-Backups laufender Systeme – ein Neustart ist nicht nötig.

Wie erstelle ich ein Raspberry-Pi-Image-Backup?

pibackup kann ein komprimiertes .img.zst-Image ihres Raspberry Pi erzeugen. Dieses Backup kann später auf dieselbe, eine größere oder kleinere SD-Karte oder sogar auf SSD/HDD wiederhergestellt werden.

Kann ich Raspberry-Pi-Backups auf USB oder NAS speichern?

Ja, Sie können Backups auf USB-Laufwerken, SSDs, HDDs oder direkt auf einem NAS speichern – dies ist die sicherste Methode zur Archivierung.

Ist pibackup eine Alternative zu raspiBackup?

Ja. pibackup ist eine portable Alternative zu raspiBackup – mit grafischer Oberfläche, Live-Backup und moderner zstd-Kompression.

Was wird immer gesichert?

pibackup sichert stets /boot und /root inklusive MBR. Das Backup deckt alles von Sektor 0 bis zum Ende der zweiten Partition ab.

Wie funktioniert das Wiederherstellen?

Während der Wiederherstellung werden /boot und /root vollständig wiederhergestellt – inklusive MBR. Zusätzlich können Sie SSH aktivieren, Benutzername/Passwort setzen und WLAN konfigurieren (SSID + PSK). Die Root-Partition kann vor dem Schreiben über die Live-GUI in ihrer Größe angepasst werden.

Kann ich die Root-Partition beim Restore anpassen?

Ja, die Größe der /root-Partition kann während des Wiederherstellungsprozesses angepasst werden. Die Live-GUI zeigt einen Schieberegler sowie eine Vorschau des Partitionslayouts an.
