Raspberry Pi Backup – Hauptfunktionen

Mit pibackup können Sie ein zuverlässiges Raspberry Pi Backup auf SD-Karte, SSD oder HDD erstellen. Unterstützt Live-Backup von laufenden Systemen einschließlich der ersten beiden Partitionen (/boot und /root).

  • Einfache grafische Oberfläche – keine Installation erforderlich
  • 64-Bit Linux Anwendung – läuft direkt
  • Automatisches Backup der ersten beiden Partitionen (/boot und /root)
  • Live-Backup-Unterstützung – Backup laufender Systeme
  • Exclude-Dateien zum Entfernen unerwünschter Daten
  • Optionales Entfernen von SSH- und DHCP-Konfigurationen
  • Image-Schrumpfung mit resize2fs und Kompression mit zstd
  • Backups als .img.zst speichern (optional)
  • Leere Sektoren mit 0xFF überschreiben für bessere Kompression & Sicherheit
  • Kompatibel mit SD-Karten, SSDs, HDDs, USB und NAS

Raspberry Pi Backup – Wiederherstellungsoptionen

Mit pibackup können Sie /boot und /root selektiv wiederherstellen, ohne andere Partitionen zu beeinflussen. Größen und Layout können in der Live-GUI angepasst werden.

  • Direktes Wiederherstellen von .img oder .img.zst
  • Selektive Wiederherstellung – nur Systempartitionen
  • Zielgerät über Dropdown wählen
  • Partitionsgröße über Schieberegler anpassen
  • Live-Vorschau des Partitionierungs-Layouts
  • Optional selektives Löschen von Partitionen
  • Dateisystem automatisch anpassen

FAQ

Wie kann ich mein Raspberry Pi SD-Karten-Backup erstellen?

Sie können ein vollständiges Raspberry Pi SD-Karten-Backup erstellen indem Sie von der Karte eine Image-Datei erstellen. Live-Backup wird unterstützt.

Kann ich nur die Systempartitionen wiederherstellen?

Ja, Sie können /boot und /root wiederherstellen, ohne andere Partitionen zu beeinflussen.
