Introduction

How the image is created

1. A 1:1 copy is created from the beginning of the device up to the end of the second partition.
The resulting .img file contains the MBR, /boot, and /root.
The complete operating system is stored in this file.
Additional partitions are not included.

2. The /root partition is mounted and becomes accessible like a normal filesystem.

3. Unwanted files are removed.

4. The partition is unmounted.

5. The image is then shrunk:

  • Unused sectors are overwritten with 0xFF
  • Removes leftover data
  • Improves compression efficiency
  • Filesystem and image size are adjusted

6. Optional compression can be applied.

Restoring the image

Under Linux (recommended)

Use pibackup for restoring.

1. MBR is taken from image and merged with partition table entries.
2. Corrected MBR + image data are written to target device.
3. Options applied:

  • /root partition size
  • passwords
  • device ID

Passwords are shown encoded.
You may enter new ones in plain text.

Under Windows

If only /boot and /root exist, the image can be restored using a standard imaging tool.

The system will boot, but /root must be expanded afterwards.

⚠ Do NOT use raspi-config if additional partitions exist.

Installing a New Operating System on an SSD

⚠ All data in /boot and /root will be lost.

1. Create new system
2. Test system
3. Install pibackup
4. Create image
5. Select source + target
6. Start restore

fstab Notes

If partitions are not mounted via automount:

sudo nano /etc/fstab

All entries must use the same PARTUUID.

pibackup Exclude File Syntax

Removes unnecessary files before compression.

/etc/pibackup/raspberry.exclude

Syntax

command = /path

§user is replaced with current username.

Commands

RF - Remove File
rf = /home/§user/.bash_history

RD - Remove Directory
rd = /home/§user/emptyfolder

RT - Remove Tree
rt = /var/lib/snapd

RFID - Remove Files in Directory
rfid = /var/backups/*

RAID - Remove All in Directory
raid = /home/§user/Downloads

RAIT - Remove All in Tree
rait = /tmp

Example Entries

rait = /tmp
rait = /var/tmp
rait = /var/cache/apt/archives
rait = /var/log

rait = /home/§user/.cache/mozilla
rait = /home/§user/.cache/chromium

raid = /home/§user/Downloads

rt = /var/lib/snapd
rt = /home/§user/snap

Compression Guide

Uses Zstandard (zstd) with long mode enabled.

Levels

1–3: Very fast, larger files

4–6: Best balance, recommended

7–10: Better compression, slower

11–19: Maximum compression, very slow

Long Mode

Improves compression by searching further back in data.

Recommended

• Pi 3: 3–5
• Pi 4: 4–7
• Pi 5: 5–10
