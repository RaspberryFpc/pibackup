Introduction

How the image is created

1. A 1:1 copy is created from the beginning of the device up to the end of the second partition.
The resulting .img file contains the MBR, /boot, and /root.
The complete operating system is stored in this file.
Additional partitions are not included.

2. The /root partition is mounted and becomes accessible like a normal filesystem.

3. Unwanted files are removed using the exclude processor.

4. The partition is unmounted.

5. The image is then shrunk:

  • Unused sectors are overwritten with 0xFF
  • Removes leftover data
  • Improves compression efficiency
  • Filesystem and image size are adjusted

6. Optional compression can be applied.

pibackup Exclude File Syntax

Removes unnecessary files before compression.

/etc/pibackup/raspberry.exclude

Syntax

COMMAND = /path

§user is automatically replaced with the current user (SUDO_USER or USER).

All paths are internally converted to absolute paths based on the mountpoint.
Escaping outside the mountpoint is blocked for security reasons.

Commands

file – Delete file(s) (supports wildcards)

Deletes files using filename or wildcard pattern.
Internally uses FindFirst, so * and ? are supported. 

file = /home/§user/.bash_history
file = /home/§user/Downloads/*.zip
file = /var/log/*.log
file = /tmp/*
Wildcard matches are limited to the current directory (non-recursive).

fileintree – Delete matching files (recursive directory traversal)

Deletes files matching a filename pattern while recursively traversing directories. The pattern is applied per directory level during traversal (not a global recursive glob search). 

fileintree = /var/backups/*.bak
fileintree = /etc/ssh/ssh_host_*
fileintree = /home/*/.ssh/known_hosts
fileintree = /home/*/.ssh/config
fileintree = /home/*/.ssh/id_*
Pattern matching is evaluated per directory during recursion. It is not a full filesystem-wide glob expansion.

allintree – Delete all contents inside a directory (keep directory)

Deletes all contents inside a directory recursively, while preserving the directory itself. 

allintree = /var/log
allintree = /tmp
allintree = /var/cache/apt/archives
allintree = /home/§user/.cache
This replaces the old DELTREE (when only content removal is intended).

dir – Delete directory completely

Deletes a directory including all content and subdirectories. 

dir = /home/§user/emptyfolder
dir = /var/tmp/unused
dir = /home/§user/.mozilla
⚠ This operation is recursive and irreversible.

Typical Cleanup Example

# temp folders
allintree = /tmp
allintree = /var/tmp

# package cache
allintree = /var/cache/apt/archives

# logs
allintree = /var/log

# browser cache
allintree = /home/§user/.cache/mozilla
allintree = /home/§user/.cache/chromium

# downloads cleanup
file = /home/§user/Downloads/*.zip
file = /home/§user/Downloads/*.img

# SSH cleanup
file = /home/§user/.bash_history
fileintree = /home/*/.ssh/*

Important Behavior

  • Paths are automatically prefixed with mountpoint
  • Invalid or unsafe paths are rejected
  • All deletions are logged (path + file)
  • Wildcard support is limited (no full recursive globbing)

Compression Guide

Uses Zstandard (zstd) with long mode enabled.

Levels

1–3: Very fast

4–6: Recommended balance

7–10: High compression

11–19: Maximum compression

Long Mode

Improves compression by increasing search window.

Recommended

• Pi 3: 3–5
• Pi 4: 4–7
• Pi 5: 5–10
